Card and interface artwork

The manifest records each original URL and file hash, the runtime PNG hash,
dimensions, and any lossless GIF-frame conversion. Runtime image files retain
the source artwork; no proprietary gameplay JavaScript is included.

Arial glyph images
  Source: Arial.ttf and Arial Bold.ttf installed with macOS, identified by
  local file URI and SHA-256 in the manifest. These are rasterized ASCII glyph
  atlases for this local build. Raw TTF/OTF/WOFF files are not included.
  The original font and glyph rights are not relicensed by this project.
